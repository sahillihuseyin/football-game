# ⚽ Final Whistle

**Final Whistle** is a football quiz game where players can test their football knowledge.

## About the Project
A football-themed game currently in development, featuring football trivia and player-based challenges.

## Technologies Used
- HTML
- CSS
- JavaScript
- JSON

## Project Files
- `index.html` — Main game page
- `draf.json` — Game data
- `players.json` — Football player data
